# 우아한테크코스 8기 프리코스 1주차 문자열 덧셈 계산기

가장 중요한 사항!!! --> 기능목록을 정리 후에 기능 목록 단위로 커밋을 해보자!!

[기능 요구 정리 ]

1. 문자열이 들어온다.
2. 쉼표 또는 콜론이 구분자로 들어온다.
3. 구분자로 분리하면 숫자가 있다.
4. 숫자를 합하여 결과값을 반환한다.
5. 빈문자열이 들어오면 0으로 처리
6. 구분자를 커스텀 할수 있다.(// 와 \n 사이에 문자를 위치하여 지정)
7. 커스텀을 할경우 구분자가 총 3개가 된다. 그의외 구분자가 있을시 잘못된 값을 입력했다 판단하고 IllegalArgumentException 발생시킨다.

[입출력 요구사항]

1. 구분자와 양수로 이루어져 있어야 한다. (음수 또는 구분자가 아닌 문자열가 입력되었을경우 IllegalArgumentException)

[구현할 기능 목록 정리]

1. 사용자 문자열 받는 기능
2. 구분자를 커스텀 생성 기능
3. 문자열을 구분자로 나누는 기능
4. 구분자로 나눴을때 양수를 밸리데이션(음수 또는 문자열 캐치)하는 기능 --> 빈문자열은 0으로 반환!!
5. 구분자로 나눠진 숫자를 합하는 기능
6. 결과값을 표출하는 기능
